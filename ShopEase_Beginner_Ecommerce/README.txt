# ShopEase - Beginner E-commerce Frontend

This is a static e-commerce frontend built using only:
- HTML
- CSS
- Flexbox

No JavaScript, React, Bootstrap, Tailwind or CSS Grid is used.

Pages:
1. index.html - Home
2. shop.html - All Products
3. product.html - Product Details
4. cart.html - Cart
5. checkout.html - Checkout
6. login.html - Login
7. signup.html - Signup
8. about.html - About

Open index.html in your browser to start.

Note:
Cart, login, signup and checkout are visual frontend pages only.
Real authentication, cart logic, payment and order processing require JavaScript/backend.
